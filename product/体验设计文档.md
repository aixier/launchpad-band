## 一、熟练用户眼里的 Launchpad(归纳)

核心感受:**手指在直接摸音乐**。

1. **它是"位置记忆"乐器,不是琴**
   - 熟手记住的是位置关系(往右一格是什么、往上一行是什么),不是音名;不看灯、不数键。
   - 类比打字:新手逐个找字母,熟手想到词,手就出去了。
2. **灯光是"显示器",不是装饰**
   - 灯承载状态:哪个片段在播、哪个轨道静音、下一个要进哪个。熟手靠灯在脑子里排整首歌的结构。
   - 因此极在意灯信息是否可靠;颜色会被当成语言(红=录音、绿=播放、黄=排队),一旦形成习惯,含义变了会很难受。
3. **最爽的瞬间**
   - 触发即响:声音和灯同时到;延迟超过十几毫秒,熟手立刻觉得"发黏"。
   - 一个手势拉起整个段落;一排键同时触发,循环叠起来,"我在搭一座东西"。
   - 现场即兴编排:同样素材每次排法不同,有"当场创作"的权力感。
4. **常见的不爽**
   - 没有力度感应,"像开关不像乐器";
   - 8×8 太小,要翻页、切模式;
   - 灯和软件状态脱节,失去信任;
   - 键帽硬而响,久弹手指累;
   - 配置比演奏还难。
5. **熟手与新手的差别**
   - 新手问"这个键是什么",熟手问"这个键现在能做什么";
   - 新手觉得灯越多越好,熟手觉得灯越少越好、每个灯都要有意义;
   - 新手追求炫,熟手追求稳。

**一句话**:熟练用户爱"可预测的手感 + 可信的灯",恨"在一片乱亮的灯里找东西"。

## 二、为什么光效 + 声音配合会"酷"

| 原因 | 说明 |
|---|---|
| 因果感 | 我按下去,灯和声同时来,大脑判定"这是我做的",掌控感远强于单纯听到好声音 |
| 多感官一致 | 看到、听到、摸到同时对上,设备像"活了";错开超过约 20 ms 就会觉得两个东西各演各的 [待验证:阈值] |
| 音乐被看见 | 节奏、和声变化、层次叠加被光变成形状和颜色,新手也能一眼懂"现在发生了什么" |
| 场面效果 | 现场观众看不到手,灯阵就是理解你在做什么的窗口 |

**酷与土的分界**
- 酷:灯光是音乐的**结果**(音高→颜色、力度→亮度、节拍→脉动),每次变化都有原因,有秩序;
- 土:灯光是**装饰**(无关彩虹乱闪、与音乐无关的循环动画),几秒就腻;
- 酷是**节制**:大部分时间克制,只有高潮才爆发,否则没有高潮可言;
- 酷在**细节**:渐变而非突变、有余韵地渐灭、涟漪向外扩散,让光像有重量。

**经验法则**:同步比炫更重要;同一时刻只一个主角;同一个音永远同一种颜色;留白(暗和亮同样重要)。

## 三、其他好体验清单(归纳)

**演奏与创作**
1. 零门槛的第一声:不懂乐理,按任何键都有声音,几秒内就玩起来
2. 搭积木式创作:先鼓、再贝斯、再旋律,一层层加,每步都有变化
3. 现场即兴编排:素材相同,每次排法不同
4. 心流:手与耳形成闭环,不用想下一步点哪里
5. 重复带来精进:同一手势越练越熟,能盲弹,成长肉眼可见

**情绪与心理**
6. 容错:音阶锁定,按错也不难听,没有"我弹错了"的羞耻
7. 掌控感:一人指挥整个场面
8. 收集感和个性:自己的布局、自己的音色库,成了"只属于我的乐器"

**社交与分享**
9. 一起玩:两人各占一半盘面,或一人弹一人调鼓,容易让不会音乐的朋友加入
10. 表演的观赏性:旁人看手和灯就能懂
11. 作品可分享:"这是我做的"

**学习与成长**
12. 在玩中学:节奏、和弦、结构玩着玩着有感觉
13. 有目标感的练习:跟着灯亮的键按,完成即有反馈
14. 清晰的进步路径:能按出声 → 能弹一首 → 能排一段

**设备本身**
15. 即插即用:USB 一插就工作
16. 安静的陪伴感:随手放桌上,想到就按几下
17. 可编程的玩具:能自己写代码做游戏、可视化

## 四、体验设计原则(本产品采用)

以下为设计决定,每条标注依据。

| # | 原则 | 依据 |
|---|---|---|
| P1 | **灯是唯一的老师**:所有"下一步怎么按"用灯色引导,不依赖文字/口头说明 | 试玩实测:文字说明"按顶排第 6 个键"无效;改灯色引导后用户**无任何文字说明独立走完整条引导链**(2026-10-26 晚,63 次按键) |
| P2 | **引导语言唯一且一致**:引导 = 青绿 + 1 Hz 硬闪烁,全局同相;青绿色相只给引导 | 用户要求"引导色和效果保持一致";确认"青绿闪的键一眼能找到" |
| P3 | **引导与演奏/演示区隔**:引导期间进入安静模式(无涟漪、无乐队侧边灯);完成奖励(彩虹/琶音/金星)是另一套语言 | 用户要求"不要在一片演示里去找";对应熟手"灯越少越好、每个灯有意义" |
| P4 | **起点与完成都有指引,完成有成就感** | 用户要求"开始线慢闪烁引导、有起始和完成指引、然后就有成就感";实测同一课从 1 星提升到 3 星 |
| P5 | **初始整盘白**:白底衬托引导和光效 | 用户要求并确认"很好" |
| P6 | **光是音乐的结果,不是装饰**:音名→颜色,按键绽放并渐褪回白,鼓点/和弦有对应的光 | 第二部分"酷与土" |
| P7 | **容错**:音阶锁定;按错不惩罚,只不前进 | 体验 6;实测错键仅闪红、不打断 |
| P8 | **同步第一**:按键到灯、到声的延迟要在可感知阈值内;不用系统 GS 音源 | 实测:GS 音源约 258 ms 不可用;自带合成器约 7 ms 进混音,到耳约 20~30 ms(估计) |
| P9 | **颜色含义不随意改**:音名色盘、控制键身份色在版本间保持稳定 | 熟手把颜色当语言 |
| P10 | **即插即用与零配置** | 体验 15;实测踩过 VMware 抢占设备、驱动问题,必须产品化处理 |

## 六、对路线图的建议

1. **近期**:验证 AI 乐队在持续弹奏时的配合(上次试玩乐队只开了一小段,未被验证);补循环层叠加录制(体验 2、3)。
2. **中期**:弹完生成整首歌(体验 11);更多课程与节奏评分(体验 14);录音变乐器(体验 8)。
3. **后期**:双人合奏(体验 9);托盘常驻随手模式(体验 16);观赏性模式(体验 10)。

## 七、待验证与风险

- 第一至四部分为归纳,未经真人访谈 [待验证]。建议找 3~5 位真实 Launchpad 用户做 30 分钟访谈,重点核对:颜色语言、延迟敏感度、最不爽的点。
- "20 ms 同步阈值"为经验说法,未实测 [待验证];本机"按键到电脑"的 USB 延迟也未测。
- 单个用户(项目发起人)的试玩不能代表小白群体;需要找至少 5 位真正的音乐小白做首次使用测试,观察"是否独立走完引导链"。
- 乐队和弦配合的效果尚未被持续弹奏验证。
